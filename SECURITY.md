# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

## Reporting a Vulnerability

Report security vulnerabilities to davi@ottenheimer.app.

You can expect an initial response within 72 hours. If the vulnerability is accepted, a fix will be prioritized and released as soon as possible. If declined, you will receive an explanation.

Do not open a public issue for security vulnerabilities.
